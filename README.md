# MixerCA
Source code for "MixerCA: An Efficient and Accurate Model for High-Performance Hyperspectral Image Classification" Accepted for publication in **Remote Sensing Applications: Society and Environment (RSASE).**


<img width="4464" height="1716" alt="image" src="https://github.com/user-attachments/assets/2beea6d2-f547-4ec4-9449-8ec84c1cf468" />

# Requirements:
Python 3.9.18, Tensorflow (and Keras) 2.10.0.

# Datasets:
The evaluation is performed on widely used hyperspectral datasets, link to the datasets along their class maps is available at:
https://mega.nz/folder/zoJDhJKI#bNj3Xr0iLenBN12QdmGccw 

# Results:
To quantitatively measure the proposed MixerCA model, evaluation metrics are employed to verify the effectiveness of the algorithm, Overall Accuracy (OA), Average Accuracy (AA) and Cohen's Kappa (k). Also, Each class accuracy has been reported.
